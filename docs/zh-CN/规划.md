# 强制固定思考&输出流程（顺序不可颠倒）

## 第2步：业务需求拆解
将任务拆分为有序执行的多个步骤，明确每一步的数据处理目标。
## 第3步：函数/功能匹配规划
为每一步操作匹配对应的SQLazy函数/功能，说明选用依据、对应文档示例。
## 第4步：分步SQLazy代码实现
按拆解顺序分段写代码，写法、传参完全贴合MD文档示例，附带步骤注释；
代码**必须**采用下方「SQLazy 代码输出格式规范（.nsql）」，确保可直接复制进 SQLazy 专属 IDE 运行；
且**必须**把第4步代码直接写入工作区 `nsql/` 目录下对应的 `.nsql` 文件（文件名按任务语义命名，如 `009_每分钟窗口统计.nsql`）。对话中仍按四步流程展示，但最终交付以 `nsql/` 下的 `.nsql` 文件为准。

# SQLazy 代码输出格式规范（.nsql）
生成的第4步分步代码，必须严格采用 SQLazy IDE 可直接运行的 .nsql 文本格式，规则如下：

## 1. 每行格式
每一行是一个步骤，用字符串表示，格式为：[<命名>=][<锚点>:]<语句>
- 「命名」：本步骤结果表的名称（如 t1、t2…，也可自定义有意义的名字），供后续步骤引用；当命名是空时，可省略[<命名> =]
- 「锚点」：本步骤要处理的对象表或表的列，若是表，则锚点写成[<表名>:]；若是表的列，则锚点就写成[<列名@表名>:]；**可为空**（留空即什么内容都不写，不是 null，省略[<锚点>:]）。为空时默认承接上一步的结果表；
- 「语句」：该步骤的 SQLazy 功能语句。

示例：
```
t1=t_1742353802112:计算列 datetime(t; 精度 分), 命名 tm
t2=排序 t
```

## 2. 每步有且仅有一个功能
每一行（每步）只能包含**一个功能**（如 计算列 / 汇总 / 对齐 / 列表 / 导出表 / 排序 …）；但语句内**函数可嵌套多个**（如 条件()、datetime()、偏移）。需要多个功能时必须拆成多步。

## 3. 跨步引用值：命名.字段
引用其他步骤产出的值时，用「命名.字段」写法。例：`列表 头 t4.min_t 尾 t4.max_t …`（引用 t4 步骤汇总出的 min_t、max_t 字段）。

## 4. 锚点 = 焦点表
第2列锚点即当前步骤处理的输入表。显式写出可跨步指定处理对象（例：t6 锚点写 t3，表示对 t3 表做对齐），留空则承接上一步结果。

## 5. 语句不换行
每步语句必须写在同一行内，**严禁换行**。

## 6. 保留字作命名需加单引号
min、max、end、start、date、time、inc、cum、sum、avg、count 等保留字若要作为命名/字段名，必须加单引号。例：`max_v 命名 'max'`。

## 7. 命名不得重复
每步命名必须唯一，不得重复。

## 完整范例（每分钟窗口统计）
```
t1=t_1742353802112:计算列 datetime(t; 精度 分), 命名 tm
t2=排序 t
t3=汇总 v 首位 命名 首v, v 末位 命名 末v, v 最小 命名 最小v, v 最大 命名 最大v; 分组 tm
t4=汇总 tm 最小 命名 min_t, tm 最大 命名 max_t
t5=列表 头 t4.min_t 尾 t4.max_t 间隔 1 分钟
t6=t3:对齐 tm; 按照 t5
t7=计算列 条件(末v 为空 则 end_value[-1] 否则 末v), 命名 end_value
t8=计算列 条件(end_value[-1] 为空 则 首v 否则 end_value[-1]), 命名 start_value; 条件(最小v 为空 则 start_value 否则 最小v), 命名 min_v; 条件(最大v 为空 则 start_value 否则 最大v), 命名 max_v
t9=导出表 tm 命名 start, (tm 偏移 1 分钟) 命名 end, start_value, end_value, min_v 命名 'min', max_v 命名 'max'
```
